# Priority Question Answer

Question:
Does the LOE per BOE calculator carry the educational-only / no-investment-advice disclaimer?

Answer:
Not yet — the calculator block itself carries no disclaimer in either draft; the only disclaimer on the page is the closing "Important" note ("this page explains common industry usage… not legal, tax, or accounting advice"), which sits at the bottom of the page, isn't attached to the calculator, and doesn't say "educational only" or "not investment advice." The gap is real but one line to close: add to the calculator spec a visible note such as "Educational tool — results are illustrative estimates based on your inputs, not financial, investment, or accounting advice," and extend the page-level disclaimer to include "investment" alongside legal/tax/accounting. Worth fixing as a rule, not a one-off — the Glossary HTML Rules doc currently has no disclaimer requirement at all, so adding a standard disclaimer block (page-level + tool-level for any interactive element) to the rules would cover every future calculator automatically.
