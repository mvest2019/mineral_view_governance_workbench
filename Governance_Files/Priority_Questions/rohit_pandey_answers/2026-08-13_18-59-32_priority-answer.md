# Priority Question Answer

Question:
Who performs the independent verification of the validation package before dossier ownership values are treated as production output?

Answer:
There is no separate QA function — independence comes from two external references plus the data-team gate. The validation package is produced by the dossier workstream (read-only, reproducible queries) but is checked against systems it doesn't control: the live portal's own rendered numbers (the Catherine Urban export match) and Nikhil's data team, who confirm or correct each finding (county coverage, the district-code blocker, "empty = final" rulings). The de-facto independent gate is that ownership values are only treated as production when Nikhil's team cuts the portal over to the 2025 collection — the standing rule is the dossier must mirror what the owner sees on login, so the data team's own acceptance of the roll is the independent verification, followed by regeneration of affected dossiers and the per-dossier release review. If the workbench wants a formally independent reviewer beyond that, one would need to be appointed — none is named in the record.
