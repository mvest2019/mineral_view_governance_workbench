# Priority Question Answer

Question:
Do the public coverage pages for owners and leases display named mineral owners, and is that PII exposure approved?

Answer:
Short answer: the owner pages do, the lease and production pages don't, and the current behaviour predates the upgrade work. Nothing new has been published, and the final call sits with Ryan.

Owner-roll county pages — yes, names are displayed. Verified live this morning, logged out, on Karnes County: 20 owner names per page in full, plus interest type (Royalty, Overriding Royalty, Working Interest) and county totals (16,080 owners, 2,502 leases). Everything of commercial value is masked with *** — per-owner lease counts, ownership category, all appraised values, ownership share, and the entire Top Owners table. The page carries a "Data Locked" notice.

Most names are entities (LLC, LP), but some are individuals and families holding through trusts — for example "2012 Jennifer Martin, Trust" and "2011 Charles W Combs Family". Worth stating precisely so the decision isn't made on an assumption that it's all corporate.

Lease and production pages — no mineral-owner names. Verified on the Karnes production page: it lists lease name and number, status, active wells, and the operator (a company), with volumes masked. No ownership listing at all.

One honest nuance on lease names. Texas lease designations often derive from the original landowner's surname — the Karnes page shows leases such as "A. Banduch A" and "A. Banduch B". These are the official Railroad Commission lease names, public regulatory record, not an ownership attribution we've made. Worth knowing, but materially different from publishing an owner list.

On whether it's approved. It has not been through a formal approval, because it is the inherited behaviour of the current live site rather than anything the upgrade introduced. The position we can offer with confidence:

The underlying data is public record — Texas county appraisal districts appraise each owner's producing mineral interest under Property Tax Code §23.175, and those rolls are public. Republishing public record is lawful and is standard in this market.
The current treatment is already conservative in shape — name visible, every value gated.
The proposed architecture holds that same line — names in the county listing, while individual owner detail pages stay gated, noindex, and on opaque IDs, so there is no indexed page per person.
Nothing in the upgrade is live. We are producing the supporting documentation and submitting it to the governance workbench so Ryan can make this call on evidence. If he wants it handled differently in the new build, this is the cheapest possible moment to change it — the structure isn't built yet, which is exactly why it's being raised now.
