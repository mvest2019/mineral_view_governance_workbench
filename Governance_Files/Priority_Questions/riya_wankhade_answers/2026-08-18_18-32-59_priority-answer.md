# Priority Question Answer

Question:
When PostgreSQL, SQL Server, and MongoDB disagree on the same record, which one is authoritative and who decides?

Answer:
The source data is considered authoritative, while PostgreSQL, SQL Server, and MongoDB are validated against it. If the databases disagree, the discrepancy is investigated based on the source and data flow, and the responsible technical/client team makes the final decision on which value should be retained.
