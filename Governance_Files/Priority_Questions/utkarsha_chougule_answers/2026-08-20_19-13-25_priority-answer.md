# Priority Question Answer

Question:
What is the approved session lifetime for "Stay Signed In," and does Google Sign-In bypass email verification or link to existing accounts?

Answer:
The user remains logged in even after closing and reopening the browser, until the persistent session expires or the user logs out.  

If a user already has an account registered with email and password, selecting “Continue with Google” using the same email address should authenticate the user into the existing account rather than creating a duplicate account. This behavior should apply from both the Login and Registration pages.
