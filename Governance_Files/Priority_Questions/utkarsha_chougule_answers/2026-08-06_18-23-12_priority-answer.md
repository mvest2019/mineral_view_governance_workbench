# Priority Question Answer

Question:
Does tracking also capture logged-out or anonymous visitors, and how are those events tied to a person?

Answer:
Yes, the User Behavior Tracking implementation captures activity for both authenticated users and anonymous (logged-out) visitors. For authenticated users, behavior records are associated with the user's unique User ID. For anonymous visitors, events are linked using a unique session identifier until the user logs in. This ensures that user activity can be tracked throughout a browsing session while distinguishing between authenticated and non-authenticated users. The handling of these identifiers and any consent/privacy requirements are managed according to the application's privacy policy and applicable data protection guidelines.
