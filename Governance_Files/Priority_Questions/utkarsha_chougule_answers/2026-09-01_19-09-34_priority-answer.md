# Priority Question Answer

Question:
Does map search return owner names or lease records, and was it checked that results stay within the signed-in user's entitlement?

Answer:
Map Search does not support searching by user name or owner name. The available search/filter options include Lease Name, County, Operator, Well Status, Field Name, and several other map-related filters.

The Map Explorer itself is accessible only to authenticated/logged-in users. For guest/unauthenticated users, the application displays the Map Explorer landing page rather than the actual interactive map and its underlying records
