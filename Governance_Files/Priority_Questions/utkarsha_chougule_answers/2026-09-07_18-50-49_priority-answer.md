# Priority Question Answer

Question:
For same-name records, who verifies rightful ownership before a claim is accepted?

Answer:
Ownership verification is currently user-confirmed rather than manually reviewed. When a user selects a record and confirms that the displayed address belongs to them, clicking “Claim” allows the record to be claimed. There does not appear to be an additional manual ownership review before the claim is accepted.
