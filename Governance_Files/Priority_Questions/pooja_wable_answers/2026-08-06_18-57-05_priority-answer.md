# Priority Question Answer

Question:
If the datasets move to public/data/ and are fetched at runtime, can anyone bypass the free-account gate by fetching the JSON files directly?

Answer:
Yes — anything in public/data/ is a public URL; anyone can fetch the JSON directly, so the free-account gate is UI-only, not data protection.
The spec already accepts this trade-off for aggregate data (the gate is a conversion mechanism), but truly sensitive rows need a server endpoint with auth/rate-limiting — the same conclusion D-014 recorded for the owner-name shards; flag it to Tushar if any comparison dataset is row-level.
