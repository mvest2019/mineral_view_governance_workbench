# Priority Question Answer

Question:
Was the hand-written zip/OOXML spreadsheet writer reviewed for formula injection and Excel compatibility before shipping?

Answer:
No formal review, but the xlsx path is inherently safe from formula injection: every value is written as an inlineStr, and Excel only evaluates formulas in <f> elements — so a name beginning = or + arrives as text. (That protection is lost if someone re-saves the sheet as CSV.)
