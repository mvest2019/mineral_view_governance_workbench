# Priority Question Answer

Question:
Are the new cover photos and logos the approved brand assets, and where are the source files stored?

Answer:
Yes, the cover photos and logos currently live on the profiles are the approved brand assets. Nothing goes up on any platform without being checked against the brand guidelines first — correct logo versions, proper color codes, right dimensions for each platform's specs, and consistent visual identity across all channels.

The source files are stored in our internal shared drive, organized by brand. Each client channel managed through Trendelier — Mineral View, BOLD, and others — has its own folder containing the master logo files, cover photo templates, icon variations, and any platform-specific crops. Files are maintained in editable formats like AI, PSD, or Figma along with the final export versions in PNG, SVG, and WebP so the team can make updates without recreating anything from scratch.

If a new asset is created or an existing one is updated, it gets added to the same folder with clear naming conventions and version numbers so there's no confusion about which file is the latest approved version. The team knows to always pull from this central location rather than using old files saved locally. If anyone needs access to the source files or isn't sure which version to use, the marketing team can point them to the right folder and confirm which assets are current.
